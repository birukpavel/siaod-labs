## Как запустить

Python 3.10+.

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

make data FOS=<путь к репозиторию курса>   # данные своего варианта
make lab01                                 # ЛР 1: самопроверка, замеры, графики
make lint                                  # black и pylint
```

ЛР 1 считается несколько минут: квадратичный алгоритм при n = 30 000 делает
около 450 млн сравнений, и каждая точка замеряется шесть раз.

Данные не коммитятся: они детерминированы номером варианта и восстанавливаются
одной командой. В репозитории остаётся только паспорт
`data/generated/manifest.json` — по нему заготовки сверяют вариант и
прекращают работу на чужих данных.

## Соглашения

- Алгоритмы и структуры данных реализуются вручную; `sum`, `max`, `pow`,
  `list`, `collections.deque` — только эталоны для сверки.
- Проверки инвариантов — явными исключениями, а не `assert`: `assert`
  отключается при запуске `python -O`.
- Каждое решение проходит четыре шага верификации: инварианты →
  репрезентативные тесты → сверка с эталоном → оценка сложности и замеры.
- Код по PEP-8, проверяется `black` и `pylint`.
